```yaml
name:        AbdulJaleel AbdulSamad

located_in:  Lagos, Nigeria
experience:  Data science, AI engineering and product delivery (fintech, edtech, health)
building:    Web, mobile, desktop, data and AI products, zero to launch
background:  Computer Science + Medicine → Data Science & AI
ask_me:      Python, SQL, Power BI, RAG, product scoping, shipping with AI agents
open_to:     AI engineering, data science and product engineering roles
```

I work end to end: the question, the data, the model, the interface, the deploy. Small projects,
that's one person. Larger ones, it's me owning that path inside a team: scoping with product,
reviewing design, and leaving a repo the next engineer can pick up without asking me.

The range is real. Air quality, power grids, edtech, fintech, a word game, an agent console.
Different domains, same discipline underneath: audit the data before trusting the model, pick
the simplest thing that holds up, ship it where people can actually use it, and report the
number that's true rather than the one that looks best.

Everything below is live. Start with any card.
